## Desktop visual QA

Перевірені viewport:

- 1280×900;
- 1366×900;
- 1440×900;
- 1920×1080.

На кожній ширині перевірено `index.html`, `catalog.html`, `map.html`, `property.html?id=pechersk-skyline` і `design-system.html`.

- Horizontal overflow: 0 px у всіх 20 комбінаціях.
- Header: стабільна висота 86 px, без sticky-перекриття.
- Каталог: 3 картки в ряд на 1440 px; висота 6 видимих карток однакова.
- Map filter: `position: relative`, не рухається за користувачем.
- Картки: перевірено довгі назви, 2 450 000 $, оренду на місяць, довгі описи й fallback фото.
- Buttons/inputs: видимі hover/focus-visible, без обрізання тексту.
- Main container: не розтягується понад 1280 px на 1920.
- Inline CSS/JavaScript: відсутні.
- Локальні assets: response 4xx/5xx і broken images відсутні.

## Виправлені дефекти

- Виправлено масштабування та clipping логотипа; використовується версія без нижнього слогана.
- Прибрано sticky-поведінку фільтрів каталогу й карти.
- Вирівняно послідовність світлих/темних секцій головної.
- Додано синхронізацію карти й списку, markers/cards active state, popup, zoom і missing-coordinate fallback.
- Додано loading/empty/error/retry для карти та завершено state machine каталогу.
- Viewing form отримала readonly-поле поточного об’єкта; manager form — optional email.
- Модальні вікна отримали explicit dialog semantics, focus trap, overlay close, scroll lock і focus return.
- Виправлено блокування body після закриття gallery.
- Detail page приховує відсутні характеристики, оновлює title/meta й має коректний 404.
- Дизайн-система доповнена radio, marker/popup, investment profile, CTA/footer, map fallback і states.
- Виправлено ширину specimen-картки в дизайн-системі.

## Відомі обмеження й mock data

- 12 об’єктів, ціни, описи, забудовники й адресні орієнтири — демонстраційні.
- 11 об’єктів мають умовні позиції на локальній CSS-карті; один навмисно показує fallback.
- Фотографії локальні й демонстраційні; права використання потрібно підтвердити.
- Контакти `+380 44 123 45 67`, `hello@dwelchain.com`, Київ, Пн–Пт 09:00–18:00 — тимчасові.
- USD є основною mock-валютою; UAH — статичний орієнтовний еквівалент.
- Browser QA виконано системним Google Chrome через Playwright; DevTools UI не потрібен, console/page errors і response statuses зчитано програмно.
- Доступність перевірена на рівні клавіатурних сценаріїв, focus-visible, labels, aria-атрибутів, state exclusivity та alt-текстів; формальний зовнішній WCAG-аудит не проводився.
